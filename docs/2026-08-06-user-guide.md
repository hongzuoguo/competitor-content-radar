# HitMuse — 使用说明（用户版）

> 面向最终用户。开发和发布要求见 `docs/operations/` 下的公开项目规范。

---

## 1. 这是什么

Windows 桌面工具：盯着你关注的抖音对标博主，自动把他们的公开视频转成文字稿，用 AI 拆解每个作品的选题角度、开头钩子、结构、爆点、亮点、可复用模式和差异化建议，并同步到飞书多维表格，帮你快速找到值得借鉴的内容套路。

## 2. 安装与启动

- 双击安装包（setup-1.0.0.exe 或更新版本）安装。
- 启动后常驻系统托盘，可以最小化，后台自动运行。
- 首次使用本地转写会下载约 239MB 的语音识别模型（自动，一次性）。

## 3. 首次配置（5 步）

1. **登录抖音**：设置页 → 抖音账号 → 「打开浏览器登录」，在打开的专属浏览器里扫码登录；遇到验证码按提示完成。
2. **配置 AI 模型**：设置页 → 模型配置 → 新建（服务商选 DeepSeek/豆包/Kimi/通义或自定义，填模型 ID 和 API Key，配置名称可留空自动生成）。也可以选「本地 Codex」，使用已安装并登录的 Codex CLI 拆解，不要求安装 Codex 桌面版。
3. **飞书同步（可稍后完成）**：在设置页使用产品提供的完整模板创建自己的 Base，再配置自己的飞书自建应用，详细步骤见第 7 节。
4. **添加博主**：博主管理页 → 添加，粘贴抖音博主主页链接。
5. **点「立即运行」**：完成第一次真实采集。右上角选「云端模型」或「本地 Codex」再运行；没配置会提示并引导你去设置。

## 4. 主要页面

| 页面 | 作用 |
|---|---|
| 总览 | 服务状态、运行环境（云端模型/本地 Codex）、任务记录、最近运行 |
| 博主管理 | 添加/删除博主，查看每位博主的作品 |
| 作品分析 | 全部作品列表，点开看 AI 拆解、完整文案、数据趋势；可手动拆解、手动导入 |
| 任务记录 | 历史运行任务、失败重试 |
| 设置 | 抖音登录/登出、飞书自建应用连接、模型配置、拆解规则、媒体保留天数等 |

## 5. 手动拆解

作品分析页选中作品 → 右侧「手动拆解」→ 流程：下载视频 → 提取音频 → 本地转写文字稿 → AI 拆解（云端模型或本地 codex）→ 完成后在「AI 拆解」tab 显示七项拆解。

- 转写失败：保留已下载媒体，可重试
- 拆解失败：保留文字稿，从拆解阶段续跑，不会重复转写

## 6. 手动导入作品

作品分析页 → 「导入作品」：
- **本地视频**：MP4/MOV/MKV/WebM，可关联博主或作为未分类作品
- **抖音视频链接**：单条视频地址（douyin.com/video/... 或 v.douyin.com/...）

自动去重（本地按内容指纹、抖音按视频 ID），不会重复转写或调用 AI。

## 7. 飞书同步

本产品不要求你完成 ISV 认证，也不使用 Webhook、OAuth 登录或开发者中转服务。每位用户创建一个属于自己飞书组织的企业自建应用，桌面端就能以应用身份直接写入用户自己的多维表格。

### 7.1 开发者和用户分别做什么

| 角色 | 需要做的事 |
|---|---|
| 产品开发者 | 在桌面端维护字段结构、自动同步和错误提示；提供完整空白模板。无需代用户创建应用，无需保存用户凭证。 |
| 用户 | 先用完整模板创建属于自己的 Base 副本，再创建并配置自建应用、开通权限、把应用加入该副本，然后在桌面端粘贴 App ID、App Secret 和副本链接。之后同步自动运行。 |

### 7.2 首次配置（只做一次）

1. 在桌面端进入「设置 → 账号与同步 → 配置飞书同步」，点击「使用完整模板」。
2. 在飞书模板页点击「使用该模板」，并在预览窗口再点击一次确认。**这一步就是复制模板**：飞书会自动新建一份独立、可编辑的多维表格，后文所说的“自己的 Base 副本”就是这份新表，不是公共模板页。
3. 进入这份刚创建的新表，确认浏览器地址栏已经变成自己的 Base 链接；后续操作都在这份新表中完成。不得将公共模板或私有母版的 URL 复制到桌面端。
4. 回到桌面端点击「打开飞书开放平台」，创建「企业自建应用」。个人免费组织也可使用，无需创建商店应用、申请 ISV 或使用 ISV 身份。
5. 在应用的「权限管理」中开通应用身份的多维表格读写/管理权限；如平台将记录、字段、数据表等权限拆开显示，请一并开通桌面端同步所需权限，然后发布应用版本。
6. 回到第 2 步新建的那份多维表格，在页面右上角依次点击「… → …更多 → 添加文档应用」，搜索并添加刚创建的自建应用，然后授予编辑/管理权限。如果搜索不到，先确认应用已开通至少一个多维表格 API 权限，并且已经发布版本。
7. 从开放平台的「凭证与基础信息」复制 App ID 和 App Secret；从自己 Base 的浏览器地址栏复制包含 `/base/` 的直链。
8. 回到桌面端填写这三项，点击「测试并连接」。连接成功后，首次历史数据会自动批量回填；以后新采集、分析完成的作品会自动增量同步，无需逐条点击。

误贴公共模板链接会被应用阻止。也可以使用空白 Base，桌面端会自动补齐同步表；但空白 Base 不会获得完整模板中的仪表盘和全部自定义视图。

如果「使用完整模板」按钮打不开，可直接打开：[HitMuse 完整空白模板](https://my.feishu.cn/base/UhZ6bYe6aafexms9WGXcomHInic)。

App Secret 只加密保存在当前 Windows 账户中，不会显示在状态页，也不会经过本产品运营方的服务器。不要把 App Secret 发给任何人或放进截图。

飞书官方参考：[申请 API 权限](https://open.feishu.cn/document/server-docs/application-scope/introduction?lang=zh-CN)、[多维表格鉴权与能力说明](https://open.feishu.cn/document/server-docs/docs/bitable-v1/bitable-overview?lang=zh-CN)、[云文档权限常见问题](https://open.feishu.cn/document/server-docs/docs/faq?lang=zh-CN)。

### 7.3 首次导入和后续新增怎么计数

- 首次有 100 条作品时，桌面端会把它们分批提交给飞书，并不是让用户操作 100 次。
- API 的计费或频控如果按“记录条数”统计，100 条仍可能被飞书计为 100 条记录；但网络请求使用批量接口，每批最多 500 条。
- 再次同步会按作品 ID 更新已有记录，不会重复新增。后续单个作品分析完成时会直接写入该作品，这只是自动增量同步策略，不是 Webhook，也不经过中转服务。

### 7.4 同步范围和归档时间

- 「同步作品发布时间范围」决定哪些新作品可以首次进入飞书。例如设为 30 天，只会新增最近 30 天内发布的作品；更早且从未同步过的作品不会进入作品分析或归档作品。
- 「飞书作品保留时间」从作品首次同步到飞书的那一刻开始计算。满设定天数后，作品会在下次同步时从飞书「作品分析」表移入飞书「归档作品」表。
- 两项设置相互独立。修改发布时间范围不会提前归档已经进入飞书的作品。

### 7.5 自动汇总表

- 「近7天增速TOP10」会在每次飞书同步时自动刷新，只统计当前仍在「作品分析」中的作品；需要最近 7 天内至少两次大于 0 的指标快照，并按互动量增速排序。初始快照为 0 时不会计算出虚高百分比。
- 「创作方向」会把当前作品统一归并为最多 8 个大类，给出作品数量、平均互动、近7天增长、代表关键词、代表作品和建议级别。每次全量同步都会对当前作品重新归并并优先沿用上次的大类名称；新作品不会不断新增第 9 类，无法合理合并时进入「其他方向」。
- 「热门内容词」只统计实际进入飞书「作品分析」的内容。程序先用 nodejieba 拆标题，再由当前选中的云端模型或本地 Codex 合并同义词、去掉泛词和残片，生成可指导创作的具体词条；作品未变化时不会重复调用模型，每次同步仍会刷新内容热度。
- 飞书词云应绑定「热门内容词」表：词条选择「热门内容词」，权重选择「内容热度」；不要再绑定「创作方向」，否则会和热门选题重复。
- 「作品分析」和「归档作品」会默认隐藏用于兼容旧看板的「账号类型」；「创作方向」默认隐藏「方向ID」，「热门内容词」默认隐藏「词条ID」。字段仍保留，不会破坏现有看板。
- 自动汇总表中由应用生成的行会自动更新；用户自己添加且不使用应用专属 ID 的行会保留。
- 原来的「报告」表会自动改名为「创作方向」，旧周报记录会被清理，不再生成每周报告。

### 7.6 连接失败怎么处理

| 桌面端提示 | 处理方法 |
|---|---|
| 应用凭证无效 | 回到开放平台重新复制 App ID、App Secret，注意不要带空格。 |
| App ID 格式不正确 / 请输入 App Secret | 检查是否粘贴了完整凭证。App ID 通常以 `cli_` 开头。 |
| 请开通多维表格应用身份权限并发布新版本 | 回到「权限管理」开通多维表格读写/管理权限，再发布新版本。 |
| 请添加应用为文档应用并授予可管理权限 | 在目标多维表格里添加文档应用；只有开放平台权限还不够。 |
| 请粘贴包含 `/base/` 的链接 | 不要粘贴 `/wiki/` 知识库链接；请在多维表格中打开原始 Base 后复制直链。 |
| 这是公共模板链接 | 先点击「使用完整模板」创建自己的 Base 副本，再粘贴副本 URL。 |
| 网络或飞书服务错误 | 本地数据不会丢失。请先检查网络；首次连接失败时，重新点击「测试并连接」；已连接后同步失败时，点击「立即同步」。 |

## 8. 常见问题

**Q：抖音登录显示不了状态 / 明明登录了还显示未登录？**
点「刷新登录状态」。如果一直不对，先点「登出」再重新登录。

**Q：点「立即运行」说模型未配置？**
右上角选的是「云端模型」→ 去设置页配置模型和 API Key；或改选「本地 Codex」。本地模式要求电脑上能执行 `codex` 命令且已完成登录；只有桌面聊天窗口、没有 Codex CLI 时无法自动拆解。

**Q：手动拆解后一直显示“正在处理”？**
转写/拆解任务一般几分钟内完成；如果超过 10 分钟没动，重启 App 后任务会变为可重试状态，点「重试拆解」。

**Q：AI 拆解显示“尚未拆解”但明明拆过？**
数据异常，联系开发者检查（2026-08-06 已修复缺字段导致的老数据问题）。

**Q：SmartScreen 提示未知发布者？**
当前安装包未配置商业签名证书，属正常现象；请只从官方渠道下载安装包。

## 9. 数据与隐私

- 作品、文字稿、拆解结果、设置都存本机（SQLite）。
- API Key 用 Windows 安全存储加密保存。
- 抖音登录仅用于你监控的博主公开内容；不会绕过登录、验证码或平台限制。
